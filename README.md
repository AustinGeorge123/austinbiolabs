## Research focus

AustinBioLabs develops computational approaches to understand molecular residual disease, drug-tolerant persistence, and cancer evolution. The first flagship project focuses on EGFR-mutant NSCLC treated with osimertinib, integrating public multi-omic and functional-genomics datasets.

## Deployment

This is a static site designed for Vercel.

- `index.html` — site content
- `styles.css` — responsive visual design
- `script.js` — navigation and reveal effects
- `favicon.svg` — site icon
- `vercel.json` — Vercel headers/configuration

No build command is required.
